# Login Test Scenarios

## Application
SauceDemo

## Feature
Login

### Scenarios

| ID | Test Scenario |
|---|---|
| TS-LOGIN-001 | Verify login with valid username and password |
| TS-LOGIN-002 | Verify login with invalid username |
| TS-LOGIN-003 | Verify login with invalid password |
| TS-LOGIN-004 | Verify login with both username and password empty |
| TS-LOGIN-005 | Verify login with username empty |
| TS-LOGIN-006 | Verify login with password empty |
| TS-LOGIN-007 | Verify login with a locked-out user |
| TS-LOGIN-008 | Verify password masking |
| TS-LOGIN-009 | Verify Login button functionality |

## Scope

The login functionality was tested using valid credentials, invalid credentials, empty fields, a locked-out user, password masking, and Login button behavior.
