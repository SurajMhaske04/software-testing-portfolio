# Project 01 — Basic Web Application Testing

## 📌 Project Overview

This project focuses on the functional testing of a web application using manual testing techniques.

The objective is to understand how a QA tester analyzes application requirements, designs test cases, executes tests, identifies defects, and documents test results.

---

## 🎯 Testing Objectives

- Understand the application's functionality
- Identify test scenarios
- Design positive and negative test cases
- Execute test cases manually
- Identify and document defects
- Perform retesting after defect fixes
- Prepare a test execution summary

---

## 🧪 Testing Scope

The project will cover:

- Login functionality
- Form validation
- Navigation
- Buttons and links
- Input field validation
- Error messages
- Positive testing
- Negative testing
- Basic functional testing

---

## 📂 Project Documentation

The project will contain:

- Test Scenarios
- Test Cases
- Test Data
- Bug Reports
- Test Execution Results
- Test Summary Report

---

## 🛠️ Testing Approach

Testing will be performed manually by following defined test cases and comparing the actual application behavior with the expected results.
