# Software Testing Portfolio

A collection of practical software testing projects covering Manual Testing, Automation Testing, API Testing, SQL/Database Testing, and QA practices.

This repository documents my practical work in software testing, with projects organized by testing area and increasing complexity.

### 1. Manual Testing

Practical projects focused on understanding and applying manual software testing techniques.

- Test Scenarios
- Test Case Design
- Test Execution
- Positive & Negative Testing
- Functional Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- Retesting
- Exploratory Testing
- Bug Reporting
- Severity & Priority
- Test Documentation
- Requirement Traceability Matrix (RTM)
- Test Summary Reports

### 2. Automation Testing

Practical automation projects covering web application testing and automation frameworks.

- Automation Fundamentals
- Web UI Automation
- Locators
- Assertions
- Test Data
- Test Frameworks
- Page Object Model (POM)
- Test Reporting
- Framework Design
- Git & GitHub
- CI/CD Integration

### 3. API & Database Testing

Projects focused on backend and data validation.

- API Testing
- HTTP Methods
- Status Codes
- Request & Response Validation
- API Test Cases
- SQL Queries
- Database Validation
- Data Integrity Testing
